Intentionally almost empty: JASE 1.x portable updates copy this folder.
Without it, updating a JASE 1.x portable copy to this version would roll back
to the old one. It can be deleted once you no longer update from JASE 1.x.

Casi vacia a proposito: las actualizaciones portatiles de JASE 1.x copian esta
carpeta. Sin ella, actualizar una copia portatil de JASE 1.x a esta version
volveria a la anterior. Se puede borrar cuando ya no se actualice desde JASE 1.x.
